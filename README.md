# git-graph

A minimalist git commit graph in a pane beside the chat: colored lanes, merge rings, branch / tag / HEAD labels, hover for author and message. It redraws after Bash tool calls and has a Refresh button. Open it with `/git-graph`.

## Install

At the prompt of a terminal session:

```
/plugin install git-graph --marketplace barnamoy-tutrowl/git-graph
```

From a shell:

```
claude plugin install git-graph --marketplace barnamoy-tutrowl/git-graph
```

It reads the git repository of the session's working directory.
